# Estrategias para la Resolución de Problemas y Toma de Decisiones

Portal educativo de la asignatura **Estrategias para la Resolución de Problemas y Toma de Decisiones**, diseñado para estudiantes de bachillerato.

## Contenido inicial

- Presentación de la asignatura.
- Programa de estudios y cuatro módulos.
- Sistema de evaluación de primer y segundo parcial.
- Módulo 1: Fundamentos y Diagnóstico de Problemas.
- Sesiones 1 a 4.
- Siete tipos de problemas.
- Recursos audiovisuales de apoyo.
- Diseño responsive y mejoras de accesibilidad.

## Módulos

1. Análisis y estructura de los problemas.
2. Estructura de la toma de decisiones.
3. Estrategias fundamentales para la toma de decisiones.
4. Aplicando estrategias para resolver problemas.
